## Learning outcomes

Official ILO pending. Typical IVE ME drawing + CAD:

- Orthographic projection, sections, auxiliaries
- Dimensioning and simple tolerances
- Assembly / detail drawings for workshop parts
- 2D CAD (usually AutoCAD) to campus standard
- Possible intro to 3D or mechanical conventions (hidden lines, threads, welds) — confirm on Moodle

This is the heaviest Sem 1 vocational module (10 cr, 39 contact hours). Treat it as the studio priority even if a partial exemption is filed.

## Workshop application

This module should produce real studio drawings, not only homework:

1. Title-block template for 物資工作室 (A3 / A4)
2. Orthographic of one jig or shelf bracket already in the shop
3. Section through a clamp or hopper joint
4. Cut list + hole chart from the drawing

Later (Sem 8 EME4279) upgrade the same parts to 3D + GD&T.

## Formulas

- Third-angle vs first-angle: confirm which IVE uses in week 1
- Scale: 1:1, 1:2, 1:5 for shop parts
- Basic fit language: H7/g6 etc. — learn when lecturer introduces it
